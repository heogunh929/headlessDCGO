# BT1_003 — 헤드리스 매핑 계획

## OnAllyAttack
- intent: When this Digimon attacks, if opponent has a Digimon with no digivolution cards in play, draw 1 card (once per turn, inherited)
- headless: ActivateClass (name: "Draw 1") with trigger gate `CanTriggerOnAttack`, activation condition `IsExistOnBattleArea` + `HasMatchConditionOpponentsPermanent`, activation action `CardEffectFactory.DrawCardsEffect(card, 1)`
- args:
  - name: "Draw 1"
  - trigger gate: `CanTriggerOnAttack(ctx, card)` (from `CanUseCondition`)
  - activation condition: `IsExistOnBattleArea(card) && HasMatchConditionOpponentsPermanent(card, permanent => permanent.IsDigimon && permanent.HasNoDigivolutionCards)` (from `CanActivateCondition`)
  - activation action: `CardEffectFactory.DrawCardsEffect(card, 1)` (from `DrawClass(card.Owner, 1, activateClass).Draw()` coroutine intent)
  - inherited: true (`SetIsInheritedEffect(true)`)
- condition: `CanTriggerOnAttack` + `IsExistOnBattleArea` + `HasMatchConditionOpponentsPermanent` (all present in brief's 심볼 조회 결과)
