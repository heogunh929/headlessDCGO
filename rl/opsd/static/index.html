리그 학습 (덱+정책 조합 학습) — "운영" 탭 내 신규 카드

① 조합 구성 — 덱 하나에 정책 하나, 행 = 조합
#덱시작 정책학습
1red_st1_bt신규 정책☑
2blue_st2_btperdeck-blue/policy.zip☑
3yellow_st3_btruns/l0-main-4/policy.zip☐
덱 = rl/decks 레시피 · 시작 정책 = 신규 또는 runs/의 기존 정책(zip). 같은 덱 중복 허용.
학습 체크 해제 = 동결 상대(스파링 파트너)로만 참전 — 학습 순번에서 빠지고 상호 승률표엔 계속 나타남(고정 벤치마크).
② 리그 설정
라운드 3 × 라운드당 조합별 300 판 · 시드 42 · 판 로그 20 판당 1
진행 규칙: 라운드마다 조합 1→2→… 순서로 학습(동시 1잡, 큐 자동). 학습 중 조합의 상대는 나머지 조합들의 최신 동결 정책+그 덱(판마다 순환). 라운드가 끝나면 동결본 갱신. 1라운드에서 동결본 없는 신규 조합의 상대 몫은 랜덤 합법 수로 대체.
③ 진행 — 리그 실행 중 표시
league-0730 · 라운드 2/3
조합이번 라운드진행
1 · red_st1_bt완료300/300판
2 · blue_st2_bt학습 중판 121/300
3 · yellow_st3_bt동결(학습 안 함)상대로만 참전
각 조합 학습 = 잡 1개 — 기존 잡 카드(RSS·정지)와 동일 표면. 라운드 종료마다 승률표 갱신.
④ 상호 승률표 — 라운드 종료마다 교차 평가
라운드 1
vs redvs bluevs yellow평균
red · r1—62%44%53%
blue · r138%—57%48%
yellow · r156%43%—50%
셀 = 행 조합이 열 조합 상대 승률(각 M판). 클릭 → 그 매치업 판 목록 → 판 뷰어.
⑤ 산출·연결
조합정책 이력
red_st1_btr1 → r2 → r3(최신)
blue_st2_btr1 → r2 → r3(최신)
runs/league-<이름>/<조합>/round-N/policy.zip 보존 — 라운드별 롤백 가능. 등록 = 기존 "RL 정책 참가자 등록" 게이트(스냅샷별 별도 참가자).

학습 덱 관리 — 대시보드 신규 탭 "덱"

대상 = 학습 파이프라인 소유 레시피(rl/decks/*.json). 아레나 참가자 덱(서버 DB)과 별개 — 포맷·검증기는 공용, 학습 덱은 카드 풀 제약 없음(실존·50장·매수만).
