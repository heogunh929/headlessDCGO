파일 하나당 에이전트 하나. 아래 템플릿의 `{{P}}`/`{{SLUG}}`/`{{HUNKS}}`만 치환해 발주한다.

작업 디렉터리: /home/hg/git/headlessDCGO

# 대상

- **AS-IS**(원본, 읽기 전용): `DCGO/Assets/Scripts/{{P}}`
- **TO-BE**(포팅 대상): `src/HeadlessDCGO.Engine/Assets/Scripts/{{P}}`
- **원시 diff**: `docs/audit/rawdiff/{{SLUG}}.diff` — 헝크 **{{HUNKS}}개**

기준: TO-BE는 AS-IS의 축자 사본이어야 한다. 다르면 그 자체가 보고 대상이다.

# 할 일

원시 diff의 **모든 헝크**와 AS-IS의 모든 멤버를 대조해, 차이를 한 줄씩 TSV로 기록한다.

## PASS 1 — AS-IS를 멤버별로 순회

**원본이 조사 범위를 정한다.** TO-BE만 보면 빠진 멤버가 보이지 않는다.
AS-IS의 각 필드·프로퍼티·메서드에 대해 TO-BE의 대응물을 찾아 대조한다.

TO-BE가 본문을 **다른 파일로 옮겼으면 따라가서 대조하라.** 옮겼다는 이유로 건너뛰면
본문 이동이 감사 회피 수단이 된다.

## PASS 2 — TO-BE를 멤버별로 순회

AS-IS에 없는 것을 찾는다. 각각에 대해 AS-IS 트리 전체를 검색해
다른 파일에 있으면 `RELOCATED`, 트리 어디에도 없으면 `INVENTED`로 판정한다.

**1패스만 돌리면 포트-전용 코드를 거의 못 잡는다**(실측: 327행 중 3행).

## 완결 조건 — 헝크 귀속

원시 diff의 헝크 {{HUNKS}}개가 **전부** 다음 중 하나여야 한다:
- TSV에 한 줄 이상으로 기록됨, 또는
- 답변에서 명시적으로 "기록 안 함"과 그 사유를 밝힘

누락된 헝크가 하나라도 있으면 미완이다.

# 출력

`docs/audit/diffs/{{SLUG}}.tsv` 에 **직접 Write**한다. 탭 구분 5열, 헤더 없음:

```
DIFF <TAB> AS-IS 절대경로:줄 <TAB> TO-BE 절대경로:줄|ABSENT <TAB> 무엇이 다른가 <TAB> CAUSE
```

4열은 무엇이 어떻게 다른지 사실만 서술한다.

**TO-BE 쪽 앵커는 줄번호와 함께 멤버 이름을 반드시 병기하라**
(예: `.../Permanent.cs:1204 (DP getter)`). 이후 기계 변환으로 줄번호가 밀려도 살아남아야 한다.

## CAUSE — 7종 중 하나

| 값 | 의미 |
|---|---|
| `MIRROR` | AS-IS 형태 이탈. substrate 탓이 아닌 것 |
| `SUBSTRATE` | substrate가 필요한 심볼을 주지 않아 생긴 변형. **어느 심볼이 없어서인지 반드시 명시** |
| `IRREDUCIBLE` | 언어/어셈블리 레벨이라 환원 불가 |
| `RELOCATED` | AS-IS의 다른 파일에 존재 |
| `INVENTED` | AS-IS 트리 어디에도 없음 |
| `EXCEPTION` | 등재된 예외 |
| `FILE_STUB` | 파일 전체 미포팅. 그 한 줄이 출력 전부 |

# 규율

- **TO-BE의 주석을 판정 근거로 쓰지 마라.** 감사 어투로 줄번호까지 달려 있지만 실증된 허위가 다수다.
  AS-IS 주석은 원본 자신의 기록이므로 사용해도 된다. 불신은 **비대칭**으로 건다.
- 분류 전 `docs/audit/sanctioned_exceptions.md`를 읽어라. **거기 등재된 범위 안**인 것만 `EXCEPTION`이다.
  새 예외를 네 판단으로 추가하지 마라.
- `SUBSTRATE`로 분류하려면 **어떤 심볼이 없어서 그 변형이 강제됐는지** 실소스 근거를 대라.
  근거 없이 "substrate라서"로 넘기지 마라.
- "사문이다 / 호출부가 없다 / 도달 불가"를 주장하려면 **grep 출력을 첨부**하라.
  AS-IS를 grep할 때는 **반드시 `-a`(`--binary-files=text`)** 를 붙여라 —
  AS-IS에 비-UTF8 바이트가 있어 붙이지 않으면 해당 파일이 **무증상으로 스킵**된다.
  TO-BE 호출부가 없다는 것은 판정 근거가 되지 못한다. TO-BE는 개발 중이고, 기준은 AS-IS다.
- **시나리오·도달성·심각도·우선순위·권고를 쓰지 마라.** 사실 서술만 한다.
  "이 차이로 문제가 생기는 시나리오를 못 만들겠다"는 판정이 아니다.
- 무죄 정당화 어휘("괜찮다 / 문제없다 / behavior-neutral / 결과 동일하므로")를 쓰지 마라.
  결과가 같아도 형태가 다르면 기록 대상이다.
- 차이가 몇 개 나와야 한다는 목표치는 없다. 많아도 적어도 상관없다. 있는 대로 기록하라.

# 금지

- `git reset`, `git stash`, `git checkout -- <path>` 등 작업 트리를 버리는 명령 **절대 금지**.
  미커밋 변경이 다수 섞여 있다. 필요하다고 판단되면 중단하고 보고하라.
- `git commit` 금지. 소스 파일 수정 금지 — 이건 읽기 전용 감사다.
  쓰는 것은 네 TSV 파일 하나뿐이다.
- `DCGO/` 수정 금지.
